Deep Learning for NMR Signal Classification

Final-year engineering project carried out in collaboration with INRAE. The objective is to detect water-stress conditions and classify herbaceous plant species from NMR-MOUSE relaxometry signals (T2) using 1D and 2D convolutional neural networks.

Two-stage training strategy — pre-training on simulated data followed by fine-tuning on real experimental data — with a modular Python pipeline including Bayesian hyperparameter optimization (Optuna, TPE), repeated stratified cross-validation, and model explainability using Grad-CAM++.

Deep Learning PyTorch Optuna Signal Processing Grad-CAM++
